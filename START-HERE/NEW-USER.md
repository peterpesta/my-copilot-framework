# New User Guide

## What you downloaded

A reusable personal context framework. It is not preconfigured memory and it is not an automatic recorder.

## Step 1: Create your working copy

Copy `INSTALL/starter-kit/` into an organisation-approved OneDrive location. The copied folder becomes your private working copy.

Rename `06 Weekly Reviews/YEAR Weekly Reviews.md` to the current year, for example `2026 Weekly Reviews.md`. Start a new file each January.

See `docs/EXAMPLE.md` for what completed files and agent responses look like.

## Step 2: Complete the foundation

### 01 Me.md
Record durable role context, goals, ways of working, principles and how you want Copilot to help.

### 02 Current Focus.md
Complete CURRENT with priorities, outcomes, deadlines, follow-ups and blockers.

### 07 Career Vision.md
Record the professional direction you want to explore.

### 09 Personal Brand.md
Record how you intend to contribute and what you want to be known for professionally.

## Step 3: Add one project only if useful

Copy `03 Projects/PROJECT TEMPLATE.md`, rename it, and add the project to `PROJECT INDEX.md`.

## Step 4: Create the recommended agent

Follow `AGENT-RECOMMENDED/SETUP.md`.

The intended result is one reusable interface that understands:

- what the framework files mean;
- which context is current versus historical;
- how to combine available work knowledge with curated personal context;
- how to propose safe framework updates.

## Step 5: Test

```text
What do you know about my current focus from My Copilot Framework?
```

Then:

```text
Start my day.
```

The response should distinguish recorded framework priorities, current-work evidence and AI suggestions.

## Step 6: Build naturally

Do not complete every template immediately. Add decisions, ideas, reviews and learning when real work creates meaningful context.

## If you cannot create an agent

Use `FALLBACK-NO-AGENT/README.md`. The framework remains useful, but you will manually attach or reference the smallest relevant files in normal Copilot Chat.
