# Daily and Weekly Use

## Morning

```text
Start my day.
```

Expected outcome:

- recorded priorities;
- configured current-work evidence;
- blockers and important follow-ups;
- up to three suggested next actions;
- clear separation between commitments and suggestions.

## Resume work

```text
Continue [project].
```

Expected outcome:

- recorded project state;
- relevant current-work changes;
- decisions and open questions;
- next steps and verification needs.

## Preserve something

```text
Remember this in my framework.
```

Expected outcome:

- exact target filename;
- action such as APPEND or UPDATE CURRENT;
- ready-to-paste Markdown;
- explicit statement that it was not written unless a write was confirmed.

## Explore

```text
Explore this idea using my context.
```

The agent should distinguish previous recorded ideas from new suggestions.

## End of day

```text
Close my day and identify only what deserves preservation.
```

## Weekly review

```text
Help me reflect on this week using recorded framework context and available current-work evidence. Separate outcomes, decisions, learning, blockers and next priorities. Do not score my performance.
```

## Periodic sync

```text
Compare current confirmed understanding with My Copilot Framework and propose updates by target file. Preserve history and do not claim updates were saved.
```

## Simple rule

If it is useful only today, leave it in Microsoft 365. If future you may need the meaning, rationale, direction or learning, preserve it in your framework files.
