# Design Principles

1. Framework files are curated memory.
2. Microsoft 365 provides work activity and evidence.
3. Copilot provides reasoning.
4. The agent is the recommended interface, not the source of truth.
5. Human judgement decides what deserves persistence.
6. Stable files, evolving content.
7. Current state and history remain distinguishable.
8. Authoritative sources verify organisational facts.
9. AI proposes; humans review; files preserve.
10. Upgrades never overwrite personal history.
