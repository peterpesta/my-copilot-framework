# Use Cases

## Start the day
Combine recorded focus with configured current-work knowledge.

## Return from leave
Compare the context left behind with current activity and identify meaningful change.

## Resume a project
Use curated project memory plus fresh evidence.

## Revisit decisions
Surface recorded rationale before reopening an old question.

## Develop ideas
Reconnect saved ideas with current priorities.

## Weekly reflection
Preserve outcomes, decisions, learning and blockers.

## Self-review preparation
Organise the user's evidence without automated scoring.

## Career development
Connect current projects and learning with stated career direction.
