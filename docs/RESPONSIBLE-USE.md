# Responsible Use

- Store personal working files only in approved locations.
- Follow organisational privacy, classification, retention, IP and acceptable-use requirements.
- Add only knowledge sources the user is authorised to access.
- Verify consequential facts against authoritative sources.
- Keep recorded facts, inference and recommendations distinguishable.
- Use self-review workflows for evidence gathering, not automated performance scoring.
- Review agent outputs before adding them to durable memory.
