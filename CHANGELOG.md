# Changelog

## v1.0.0 — 2026-10-23

First public release.

- Personal context framework for Microsoft 365 Copilot built on plain Markdown files.
- NOW / MEMORY / DIRECTION file structure with starter templates.
- Recommended My Copilot Framework Agent: setup guide, instructions and conversation starters.
- Fallback workflow for normal Copilot Chat without an agent.
- New-user guide, daily and weekly routines, and a worked example.
- Architecture, design principles, maintenance, use cases, responsible use and privacy guidance.
