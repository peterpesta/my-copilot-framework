# Recommended My Copilot Framework Agent

## Why the agent is recommended

The files alone preserve memory, but an agent gives the system a reusable front door.

It can reduce repeated setup by keeping:

- framework-specific instructions;
- file-role definitions;
- workflow rules;
- available configured Microsoft 365 knowledge;
- consistent source and verification behaviour.

## The agent is not the memory

The framework files remain canonical curated memory. Chat remains a working session.

## Knowledge configuration

Use only sources available and authorised in your Microsoft environment. Depending on the agent-building experience and tenant configuration, knowledge options may include organisational files, SharePoint, work email, Teams chats and meetings, websites, profile information or connector-indexed data.

Do not describe a source as available until it has been configured and tested.

## Setup

Follow `SETUP.md`, then paste `INSTRUCTIONS.md` into the behaviour/instructions area where supported. Add the starters from `STARTER-PROMPTS.md` where supported.
