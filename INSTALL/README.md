# Installation Checklist

1. Copy `starter-kit/` to an organisation-approved OneDrive location.
2. Rename `06 Weekly Reviews/YEAR Weekly Reviews.md` to the current year, for example `2026 Weekly Reviews.md`.
3. Complete 01 Me.md.
4. Complete CURRENT in 02 Current Focus.md.
5. Complete 07 Career Vision.md.
6. Complete 09 Personal Brand.md.
7. Add one project only if useful.
8. Create the recommended agent using `AGENT-RECOMMENDED/SETUP.md`.
9. Test source boundaries and Current Focus.
10. Start with `Start my day.`

## Complete when

- your working copy is in an approved OneDrive location;
- the foundation accurately reflects the user;
- the agent is configured and tested, or the fallback is understood;
- no private material was published to GitHub;
- FRAMEWORK-VERSION.md shows v1.0.0.
