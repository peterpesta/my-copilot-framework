# Contributing

Thanks for your interest in improving My Copilot Framework.

## How to contribute

1. Open an issue first to describe the problem or idea.
2. Keep changes small and focused; one topic per pull request.
3. Explain the reason for the change and who it helps.

## Guidelines

- Keep the framework role-neutral, human-readable, source-aware and non-destructive.
- The framework files remain the memory layer; the agent remains the recommended interface.
- Any change to file structure or file names must include migration guidance, so existing users never lose their history.
- Use British English spelling for consistency with the rest of the repository.

## Never include personal data

Do not submit a populated personal copy, real names, real projects or anything from your organisation. Use invented examples only.
